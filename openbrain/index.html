This is the placeholder index.html in the repo. The real dashboard ships embedded inside wormhole.exe and is served from the binary at http://127.0.0.1:18790/ when you run wormhole serve.

If you want to develop against a disk-served version, point tower_http::services::ServeDir at this directory in wormhole/src/ui.rs. The widgets and nodes config files live alongside this file.
