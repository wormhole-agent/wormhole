# Humanizer

When asked to humanize text:

1. Read the text carefully.
2. Remove these AI tells: "delve", "leverage", "utilize", "comprehensive", "robust", "seamlessly", "groundbreaking", "revolutionize", em dashes (—), and any phrase that sounds like marketing copy ("unlock the power of", "in today's fast-paced world", "at the end of the day", etc).
3. Rewrite in Richard Feynman "Curious Explainer" voice: short sentences, vivid analogies, plain words, playful tone. Show the gears turning. Pick concrete nouns over abstract ones.
4. Keep the same meaning and all specific facts. Don't invent. Don't soften claims.
5. Return ONLY the rewritten text, no commentary, no preamble.

If the text is already plain and human, return it unchanged and say so in one short line.
