# Chained-Research Prompt Template

Copy this, fill it in, run it against the primary model. Target: 500-800 words total.

---

## Context
[Who you are, what you're working on, current state. 2-4 sentences.
Include: company/project, stage, budget constraints, team size, any binding values or ethics.]

## The decision or question
[Crisp one-sentence statement of what you're trying to figure out.]

## Current thinking
[What you're leaning toward and why. Share your bias openly so the model can push on it.
Include any options you've already rejected and why.]

## Constraints (hard)
- Budget: [$X or range]
- Timeline: [by when]
- Stack / compatibility: [what must it work with]
- Values: [anything non-negotiable — e.g. "no surveillance capitalism", "community-owned"]

## Constraints (soft — nice-to-have)
- [preference 1]
- [preference 2]

## Specific questions (number them)
1. [Narrow, answerable question]
2. [Another — force a comparison, "X vs Y and why"]
3. [A question about risk — "what kills this in 12 months?"]
4. [A question about counter-positions — "who would bet against this and why?"]
5. [A question about what I'm not seeing — "what stakeholders / markets / angles am I missing entirely?"]

## Output format
- Executive summary (5 sentences max)
- Numbered answers matching my questions above
- "Unknowns" section — things even you can't answer with confidence
- "Stronger-form arguments" — the best case for the position opposite mine
- Citations with links where possible

## Meta
- Don't hedge. If one option is better, say so and defend it.
- If I'm asking the wrong question, tell me what the right question is.
- Assume I'm reasonably technical but time-poor.
