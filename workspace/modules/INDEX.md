## Notes

- Callwords are short. One word is best. The user types "bring up <callword>" to load.
- When a module is retired, move it to `modules/_archive/<name>/` and remove the row here.
- `INDEX.md` is generated by hand for now. A future tool may scan `modules/*/CONTEXT.md` for a `callword:` front-matter field and regenerate this file automatically.
