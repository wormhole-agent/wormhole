# Troubleshooting

The page you open when something is broken. Sections: `wormhole doctor` and how to read its output, common failure modes (port already bound, vault decrypt failed, Telegram unreachable, Ollama not detected, cron job stuck), how to read the log files under `logs/`, how to file a useful bug report, and the canned recovery procedures for vault corruption, scheduled task drift, and partially-applied updates.
