# Skill Schema Reference

The markdown skill format: front-matter fields, the required "What this skill is for" paragraph, the structured sections (`Trigger`, `Steps`, `Outputs`, `Failure modes`), and the conventions the loader expects. This page is the contract: a skill that follows this schema can be loaded by `load_skill`; one that does not will fail to register. Examples and counter-examples included.
