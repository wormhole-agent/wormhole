# Install

This page walks through every supported install path for WormHole v0.1.0: build from source (the recommended path for v0.1.0), download an unsigned binary from GitHub Releases (clicking through the SmartScreen warning), and the future Phase 2 signed installer (not yet available). It explains what prerequisites each path needs, what gets created on disk, and how to back out if you change your mind.
