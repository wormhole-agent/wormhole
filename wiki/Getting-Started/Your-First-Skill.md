# Your First Skill

A skill is a markdown file under `workspace/skills/` that tells the agent how to do a specific kind of task: research a competitor, draft a Reddit post, run a chained-research sweep. This page walks through writing a tiny skill from scratch, registering it so the agent loads it on demand, testing it from the CLI, and watching the agent invoke it through the dashboard. By the end you will understand the skill format well enough to read every example skill in the repo.
