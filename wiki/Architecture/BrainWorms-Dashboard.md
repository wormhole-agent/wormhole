# BrainWorms Dashboard

BrainWorms is a single hand-written HTML page that polls JSON snapshots from the workspace and renders them as a grid of widgets. There is no build step, no bundler, no npm install. You can edit a widget in 30 seconds with a text editor. This page covers the two config files (`widgets.json`, `nodes.json`), the data contract every widget kind expects, how to add a new widget, and how the embedded server in the WormHole binary serves the page and the JSON.
