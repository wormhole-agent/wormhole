# Workspace Layout

The workspace is the agent's filesystem brain. It holds personality (`SOUL.md`), operating rules (`AGENTS.md`), long-term memory (`MEMORY.md`), daily session logs, Node tools, markdown skills, and module folders for project-specific work. This page walks every directory in the public template, says what each file is for, and points at the source code that reads or writes it. It also explains what the public template intentionally does NOT include and why.
