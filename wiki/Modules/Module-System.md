# Module System

A module is a folder under `workspace/modules/` that holds project-specific context: a `README.md` explaining the project, a `CONTEXT.md` with the relevant facts the agent should know, a `LEDGER.md` that logs what has been done, and any number of supporting files. The agent reads modules on demand. This page covers the standard module shape, the `INDEX.md` registry, how modules differ from skills (skills are how-to; modules are about-this-project), and how to keep a module from polluting global memory.
