# Writing A Module

A walkthrough of building a module from scratch using the shipped `example-module/` as a template. Steps: copy the example, fill in `README.md` (what is this project, who is the audience, what is the goal), write `CONTEXT.md` (facts the agent should keep loaded), seed `LEDGER.md` (what has happened so far), add tools or skills the module needs, and register it in `INDEX.md`. This page also explains how to retire a module cleanly when the project ends.
