# WormHole Wiki

WormHole is a binary that runs your AI assistant locally. It remembers things, runs on a schedule, and calls out to bigger models when it needs to. This wiki is the long-form version of the README. The README tells you what WormHole is in a paragraph; the wiki explains how every piece works, how to extend it, and how to recover when something breaks.

If you are new, start at **Getting Started -> Install**, then **First Run**. If you are trying to debug something, start at **Operations -> Troubleshooting**. If you want to contribute, the [`CONTRIBUTING.md`](https://github.com/wormhole-agent/wormhole/blob/main/CONTRIBUTING.md) at the repo root is the entry point; this wiki is what it points back at for explanations.

## Sections

- **Getting Started**: install, first run, write your first skill, write your first cron job.
- **Architecture**: the binary, the dashboard, the workspace, and the contracts between them.
- **Modules**: how to organize project work inside the workspace.
- **Concepts**: auto-learning, squash mode, confidence tags, the verify-before-surface rule, the V4 critique gate.
- **Reference**: schemas and API docs you look up when you are mid-edit.
- **Operations**: backup, restore, vault, updating, troubleshooting.
- **Credits**: every dependency, every named inspiration, every human contributor.
- **Changelog**: releases.
