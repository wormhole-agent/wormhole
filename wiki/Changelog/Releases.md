# Releases

Per-version release notes. Each entry covers what changed, what is new, what was deprecated, what migration steps users need to run, and the SHA-256 hashes of the published artifacts. The first entry will be v0.1.0 (the public-source release with build-from-source as the primary install path). Phase 2 releases will add signed MSI builds; the page will mark which artifacts are signed and which are unsigned.
