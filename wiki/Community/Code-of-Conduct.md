# Community: Code of Conduct

This wiki page mirrors `CODE_OF_CONDUCT.md` at the repo root. The short version is: be kind, be patient, be honest. Disagree about the work, not the person.

The full text is the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Reports go to the maintainer (see `MAINTAINERS.md`).
